# Просебя — «Моя подписка»: HTML-прототип

Кликабельный прототип раздела «Моя подписка» для сотрудника по корпоративной программе. Лежит в ветке `prototype`.

**Открыть:** https://leratk22.github.io/prosebya-subscription-prototype/

На компьютере прототип остаётся в мобильном разрешении (375 × 812), справа — панель состояний. На телефоне открывается на весь экран, панель вызывается кнопкой «Сценарии».

## Состояния по ссылке

Одна страница, состояние переключается панелью и записывается в адрес. Ссылку на конкретное состояние можно отправить:

| Ссылка | Состояние |
|---|---|
| [`#s04`](https://leratk22.github.io/prosebya-subscription-prototype/#s04) | Лимит на компанию у трёх специальностей, у остальных скидки или полная цена |
| [`#s04p`](https://leratk22.github.io/prosebya-subscription-prototype/#s04p) | То же, но лимит личный (на клиента) |
| [`#s03`](https://leratk22.github.io/prosebya-subscription-prototype/#s03) | Лимит компании доступен, числа скрыты |
| [`#s06`](https://leratk22.github.io/prosebya-subscription-prototype/#s06) | Лимит компании исчерпан |
| [`#s05`](https://leratk22.github.io/prosebya-subscription-prototype/#s05) | Личный лимит исчерпан (подписка с личным лимитом) |
| [`#s01`](https://leratk22.github.io/prosebya-subscription-prototype/#s01) | Только личные лимиты |
| [`#s07`](https://leratk22.github.io/prosebya-subscription-prototype/#s07) | Только скидки |
| [`#s08`](https://leratk22.github.io/prosebya-subscription-prototype/#s08) | Временная блокировка бесплатного доступа |
| [`#s09`](https://leratk22.github.io/prosebya-subscription-prototype/#s09) | Постоянная блокировка |
| [`#x01`](https://leratk22.github.io/prosebya-subscription-prototype/#x01) | Загрузка |
| [`#x02`](https://leratk22.github.io/prosebya-subscription-prototype/#x02) | Ошибка загрузки |

В панели «Настроить вручную» состояния собираются из отдельных параметров: подписка, лимит компании, числа компании, личный лимит, блокировка, экран.

## Настройка «Цена и слово „Бесплатно“»

Настройка в блоке «Настроить вручную». Работает поверх любого сценария и записывается в ссылку:

| Ссылка | Что включено |
|---|---|
| [`#s04&money=1`](https://leratk22.github.io/prosebya-subscription-prototype/#s04&money=1) | «Меньше про деньги» на подписке с лимитом компании |
| [`#s06&money=1`](https://leratk22.github.io/prosebya-subscription-prototype/#s06&money=1) | «Меньше про деньги», лимит компании исчерпан |

- **Меньше про деньги** (`money=1`): у бесплатных карточек нет рублей. «Бесплатно» стоит под названием вместо «0 ₽», у платных под названием небольшая цена, а цена после лимита перенесена в «Условия подписки».
- **Дата обновления лимитов** стоит в карточках специальностей с лимитом (обновляются только лимиты). У карточек с исчерпанным лимитом дата тоже есть, у заблокированных нет. В плашке программы её нет.
- В подписке лимит либо на компанию, либо на клиента, но не оба сразу: на одном экране не встречаются «Личный лимит» и «Общий лимит компании» вместе.

## Что работает

- нажатие на специальность открывает заглушку каталога с текущей ценой; «назад» возвращает в список;
- ⓘ в карточке программы — «Условия подписки»; красная ⓘ при блокировке — «Об ограничении»;
- «Повторить» на экране ошибки запускает загрузку и возвращает экран;
- переключатель «Лимит компании закончился, пока человек выбирал» показывает в записи новую цену.

## Что важно знать

- Все цены, остатки и даты демонстрационные.
- Описания специальностей и иконки взяты с сайтов Просебя. Для нутрициолога использован текст «ЗОЖ-эксперта».
- Шрифт Euclid Circular A подключён файлами из папки `fonts/` (`@font-face`), поэтому одинаково отображается в Safari, Chrome и на телефоне. Файлы лицензионные, использовать только в рамках лицензии.
- Каталог и запись — заглушки, в прототипе не реализованы.
- Прототип не проходил пользовательское тестирование, правила блокировок и порядок специальностей требуют подтверждения продуктом.
